# Афарар Proxy

Клиент для Android с **автоматическим переключением серверов**. Если текущий сервер недоступен или работает медленно, приложение ищет подходящую замену — без ручного перебора конфигураций.

Особенно полезно при нестабильной связи и меняющейся доступности серверов в российских сетях. Качество соединения зависит от сети и вашего провайдера.

[Скачать приложение](https://github.com/usach77/Afarar-Proxy/releases/latest) · [Сообщить о проблеме](https://github.com/usach77/Afarar-Proxy/issues)

Android 7.0+, ARM64. Для работы нужна подписка или конфигурация от провайдера.

Полные исходники и лицензии — в архиве `Afarar-Proxy-<версия>-source.zip` каждого выпуска. Основано на v2rayNG (GPLv3).

Ранее — Mevi Proxy. Версия 0.4.32 переводит обновления в этот репозиторий с сохранением подписок и настроек.
